# 项目本地演示验收记录

日期：2026-11-12。验收结论：M1–M4 的**本地 Mock 演示链路通过**；真实数据、模型精度和真实 Neo4j 性能仍待验证，不构成完整生产或课程指标验收通过。

## 交付范围

- M1：FastAPI 基础鉴权、任务、内存/Neo4j 仓储、SQLite 审计和匿名图数据；真实 Neo4j 集成仍需配置服务。
- M2：本地图片和视频解码、Mock 轨迹、YOLOv8/ByteTrack 适配入口、时空共现强度；演示运行使用合成轨迹，不读取画面中的人员身份。
- M3：PyG GNN 前向推理与检查点、窗口证据输入、多跳查询。演示使用随机初始化模型和合成特征，概率未校准、全部标记不确定。
- M4：Vue 3/Vite/Pinia/Element Plus 前端，媒体上传及任务进度、ECharts 图谱与多跳查询、隐私和审计页面；Vite 代理及本地 CORS 配置。

## 本次验证

- 后端与算法自动测试：77 项通过、1 项真实 Neo4j 集成测试跳过，代码行覆盖率 90.45%。覆盖上传授权、非法文件、任务状态、Mock 推理、图谱及审计权限、CORS 和跨用户访问。
- 前端 Vitest：5 项通过，覆盖 API 授权、错误、图谱数据映射，以及上传、启动、读取图谱、审计和页面导航。
- Vite 生产构建和开发服务器启动通过。使用运行中的 Vite 代理和 FastAPI，真实 HTTP 联调完成：生成测试图像 → 上传 → 创建并运行 Mock 任务 → 查询两个节点、一条边和审计记录。
- 自动化 HTTP 联调不等同浏览器人工验收。Vite 构建成功，但主 JavaScript 包约 2 MB，提示超过 500 KB；测试客户端有一条 Starlette 弃用提示。
