# 人员关系推断系统分阶段开发计划

**目标：** 按 M1 至 M4 构建可追溯、可测试的授权媒体分析与关系图谱系统。  
**架构：** FastAPI 通过仓储接口访问内存或 Neo4j；异步算法管道输出匿名图数据；Vue 3 经 API 展示结果。  
**技术栈：** Python 3.12、FastAPI、Neo4j、YOLOv8、ByteTrack、PyTorch Geometric、Vue 3。  
**规范：** `AGENTS.md`；四份前期工程文档。  
**状态：** 用户已确认；2026-11-12 按缩定范围验收 M1 核心后端并进入 M2。下列原始 M1 未勾选项保留为后续待办，不再作为本次封存的阻塞项。

## 全局约束

- 严格使用 `AGENTS.md` 的 API 路径、技术栈、隐私和指标约定；每阶段先定义测试，再实现并验证。
- 未授权数据不得处理；匿名标识不可逆，输出必须说明不确定性和适用边界。
- 已实现后端和算法业务代码的单元测试行覆盖率 >= 80%；测试不得依赖真实用户数据。
- 核心同步接口服务端响应 < 1 秒；在真实 Neo4j 和约定数据规模下记录查询集、并发、P50/P95 和测试环境。
- mAP >= 0.75、关系准确率 >= 0.80 为暂定目标；分别在 M2、M3 实验后复核，不预设数据集足以达到目标。

## 文件职责

- `backend/app/`：FastAPI 路由、配置、认证授权、任务、审计、脱敏和图仓储；`backend/tests/` 对应测试。
- `backend/app/repositories/`：图仓储协议、内存实现、Neo4j 实现；业务层不直接调用数据库驱动。
- `ai_pipeline/`：媒体预处理、检测跟踪、ReID、共现特征、关系模型与评测；`ai_pipeline/tests/` 覆盖计算。
- `frontend/`：Vue 3 页面、图谱交互、API 客户端与前端测试。
- `docs/`：API/图模型契约、数据及标签方案、实验与性能报告；不得存放密钥或未授权数据。

## M1：后端、仓储与安全

- [ ] 定义版本化 API 请求、响应、分页、错误码、角色矩阵和图模型字段；保留任务与结果来源，明确无记录与服务不可用的区别。
- [ ] 建立 FastAPI 应用、配置、健康检查、请求 ID 和统一错误响应；用接口测试覆盖正常、参数错误及内部失败。
- [ ] 定义 `GraphRepository` 协议，覆盖匿名节点及关系的幂等写入、按授权范围过滤的查询、分页及连接生命周期；业务服务只依赖协议。
- [ ] 实现 `InMemoryGraphRepository`，为测试注入独立实例；覆盖重复写入、自关系拒绝、过滤、分页和空结果。内存数据不跨进程或重启持久化。
- [ ] 实现 `Neo4jRepository`，本地默认 Bolt 7687，支持 Aura 加密 URI、参数化 Cypher、约束及关闭连接；对两种实现运行共同契约测试。无数据库时标记真实集成测试跳过，不得算作通过。
- [ ] 实现异步任务创建、状态查询、取消和重试的接口及状态机；无算法实现时清晰表示未接入，不虚报分析成功。正式模式任务状态需持久化，内存测试模式明确仅临时使用。
- [ ] 完成认证、JWT 刷新与失效策略、RBAC、受控媒体校验、敏感字段脱敏和只追加审计；测试匿名、越权、恶意输入、导出与日志泄漏。
- [ ] 实现图谱和两人关系查询的 API 契约及授权过滤；未接入模型时只返回已有测试数据，不伪造推断。
- [ ] 执行 `python -m pytest backend/tests --cov=backend/app --cov-report=term-missing --cov-fail-under=80`；执行真实 Neo4j 集成测试并记录结果，无法连接时保留未通过的验收项。

M1 退出条件：内存模式的后端逻辑和单测通过，覆盖率达标；真实 Neo4j 连接、持久化、约束、仓储契约另行通过后才能宣称数据库集成完成。

## M2：视觉与共现

- [ ] 确认授权数据集、身份隔离划分和保留期；安装并锁定兼容 CUDA 的 PyTorch、YOLOv8 与追踪依赖，记录 GPU 验证结果。
- [ ] 实现媒体帧读取、YOLOv8 人员检测、ByteTrack 跟踪及轨迹质量记录；测试空帧、遮挡、错误输入与轨迹切换。
- [ ] 实现 ReID 代表帧提取、匿名匹配和不确定输出；避免将低置信度匹配强行合并。固定评测脚本，报告 mAP、CMC Rank-1 和错例，复核 0.75 暂定目标。
- [ ] 定义时间窗口、坐标单位与缺失数据处理；实现共现频次、持续时间、距离、运动一致性、归一化及版本化强度计算。测试边界窗口、空轨迹、自关系和重复输入。
- [ ] 将管道作为异步任务接入仓储，验证失败、取消、重试幂等及版本追溯；运行覆盖率与端到端测试。

M2 退出条件：授权样例可产生轨迹、匿名节点和可追溯共现结果；评测报告如实记录指标和不足。

## M3：图推断与性能

- [ ] 与项目角色确认关系类别、方向、标注证据、负样本和不确定阈值；按身份或视频源隔离数据集。
- [ ] 实现非图基线与 PyG 模型，统一特征、划分和版本记录；测试图构建、自关系排除、低置信度和模型不可用。
- [ ] 将强度、类别、置信度、时间、证据、模型及任务写入图谱；评估准确率、宏平均 F1、混淆矩阵和错例，复核 0.80 暂定目标。
- [ ] 在真实 Neo4j 建立并验证索引、分页与查询深度限制；运行典型及边界查询，记录规模、并发、P50/P95，验证核心同步接口 < 1 秒。
- [ ] 对失败回滚、幂等、审计和权限执行回归；更新实验报告和版本化 API 契约。

M3 退出条件：关系结果可查询且可追溯，基线对比与真实性能证据完整；未达目标时记录差距及处理决定。

## M4：前端与联调

- [ ] 创建 Vue 3 应用及认证、任务创建和进度页面；测试登录失败、空状态、取消及错误提示。
- [ ] 实现匿名人员图、筛选、缩放、拖动、两人关系详情、证据与不确定性展示；无记录、无权限与服务不可用分别提示。
- [ ] 接入脱敏导出和审计权限，确保浏览器不直连数据库或暴露敏感数据；测试越权和异常响应。
- [ ] 执行授权样例从导入到图谱查询的端到端验收，以及前后端、安全、恢复与浏览器测试；记录性能、缺陷和演示证据。

M4 退出条件：核心演示流程、隐私和审计验证通过，严重缺陷关闭，部署和恢复说明齐全。

## 跨阶段重点检查

- 数据未授权或保留期过期时拒绝处理并记录审计。
- 数据库不可用时返回明确错误，不伪装为零结果或切换到内存模式。
- 同一任务重试或并发写入不产生重复节点和边。
- 特征缺失、模型低置信度或人员未出现时明确表达不确定或无记录。
- 跨任务和跨角色查询、日志及导出不能泄漏原始媒体、身份信息或密钥。
